A Python 3 calculator used from the Terminal, built step by step in SCCM4910.
## What it will do
Add, subtract, multiply and divide two numbers; display the result.
## How to run it
Run: python3 calculator.py
Enter the first number, operator (+ - * /), then second number.
The program prints Result: followed by the answer.

Tests depend on there not being a divisor of 0
To test the code you do ~/h-drive/calculator/run.sh
If all 5 tests pass the code should be suitable for merge
Tpee echo $? to see how many tests failed immediately after test
